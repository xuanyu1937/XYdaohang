## 四、方法说明（口径统一）

1. **页面左右外边距**以"侧栏 + 内容区"作为整体口径：≤768 侧栏是抽屉（移出视口），
   ≥1024 侧栏展开为 238px 常驻列。直接用首张卡的 `x` 会把侧栏宽度算成左边距，
   在 1024 产生 268px 的假不对称。本版量取统一取 `min(侧栏左缘, 分组卡左缘)`。
2. **星标垂直居中**只在列表态判定；网格态的星标是卡片右上角角标（另一种版式）。
3. **内容列**取全部卡片的 `.site-info` 实宽最小值，避开 `display: contents`
   下 `gridTemplateColumns` 的中间态假值。
4. **热门条可横滑**以 `scrollWidth > clientWidth` 判定，`overflow-x` 为 `visible` 时不算可滑。
