站内品牌块（唯一图形真源盾牌 path）、favicon、应用图标全部统一为 **令牌蓝 #0066CC 圆角方块 + 白色盾牌**：

- 站内品牌块：CSS mask 盾牌，亮 `#0066CC` / 暗 `#2997ff`（同色相提亮）。
- favicon：`favicon.svg`（矢量）+ `favicon.ico`（16/32/48）+ `favicon-16/32/48.png`，16px 白盾蓝底可辨、无白底方块。
- 应用图标：`icon-192/512/maskable-512.png`，主色全部精确 `#0066CC`，三张完全相同。
- manifest 移除后台白底横版 Logo JPG 置顶，添加到桌面用 assets 盾牌图标。
