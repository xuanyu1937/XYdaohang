- **问题10（P0）品牌块归位**：撤销 v2.18.18 把 mask 直接作用于 `.brand-mark` 容器的做法（导致容器丢失、盾形外侧灰描边）。容器恢复白底 / 1px 描边 / 8px 圆角 / 44(手机)·52(桌面)，与右侧图标按钮同源；盾牌下沉到 `::before` 伪元素绘制，无沿盾灰线，center 定位上下留白均衡。
- **问题1（P0）**：撤销 v2.18.17 手机端 56px 右安全区，分组卡与热门条四视口同宽、右缘一致（误差 0px），页面左右外边距对称。
- **问题2（P0）**：悬浮层 fixed 不占文档流，收起/展开两态 `.site-card` 宽度完全相同。
- **问题3（P0）**：内容列回到 ≥200px（手机实测 204px），按 15px 站名字号可容 13 汉字再省略。
- **问题4（P0）**：分组卡与热门条边框统一 `1px solid rgba(0,0,0,.30)`（暗色 `.24`），计算值字符串完全相同。

- **问题6（P1）**：标题栏/筛选占位移到热门条之前，两块表面间距统一 24px；手机标题中心与品牌块中心偏差 0px。
