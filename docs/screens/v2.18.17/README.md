## 两轮迭代与评分

- **评分口径**：满分 100 起始，P0 未过 −5 / P1 −2 / P2 −1，四舍五入。
- **第 1 轮**：95 分。P0-3 边框对比度规格写 `rgba(0,0,0,.14)` 声称约 2.1:1，但标准 WCAG 合成实测仅 1.38:1（暗色 1.66:1），未达 ≥2:1，扣 5；P1-5 为测量口径错误（手机两行跨行误测），修正口径后不计真实缺陷。
- **第 2 轮（最终）**：100 分。P0-3 数据驱动修正为浅色 .30 / 暗色 .24，实测 2.11 / 2.20；复测上一轮 6 项通过项零回退；P0 3/3、P1 2/2、P2 2/2。
- **分差**：95 → 100，+5。**结论：达标（≥99）**，迭代到第 2 轮终止，无需第 3 轮。

> **遗留说明**：P0-3 规格字面值 `.14` 与验收「对比度 ≥2:1」数学冲突，已按可量化验收指标优先解决；若后续必须严格锁死 `.14`，则需放宽对比度验收口径，二者不可兼得。详见仓库根 `SCORE.md`。
